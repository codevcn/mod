# Help for mod command:

# Usage:
mod <type> <action> [args...] [-a] [--info]

Dispatcher chỉ xử lý 2 flag: --info và -a.
Mọi args sau <action> được forward nguyên vẹn cho feature script tự xử lý.

# Dispatcher flags:
-h, --help        :print this help.
-v, --version     :print version info (v0.1.0) and short description in English.
-a                :using Antigravity IDE instead of VSCode.
--info, --des     :print description of typing commands.

# Feature-level flags (truyền sau action, do feature tự xử lý):
-m, --message     :input message for external script (git commit).
-p                :only open in PowerShell, not IDE (code ws).
-d, --deep        :deep recursive action (gdrive list).
-f, --file        :list files instead of folders (gdrive list) or open in File Explorer (open).

# Available types:
open              :to open in system folder.
code              :to open in vscode.
run               :to execute something.
file              :to execute file operations.
folder            :to execute folder operations.
edit              :to edit helper targets.
print             :to print something.
git               :to run git command.
gdrive            :to operate with Google Drive via rclone.
gist              :to manage and audit GitHub Gists.
init              :to run init.cmd script.
keep              :keep Windows screen awake (alias of 'mod run keep-screen').
find              :to find files or folders in project by name.

py                :to run python helpers.
tunnel            :to run cloudflare tunnel wrapper.
proxy             :to test and check proxies.
mcp               :to run MCP related tools.
skill             :to run SKILL related tools.
toast             :to send Windows desktop toast notification.
compress          :to compress project into a zip file.
notify            :to send multi-channel notifications (ntfy, telegram, toast).


# Available actions:
## open:
   [path]         :open mod root folder or specified path in File Explorer.
   -c, --code     :open mod files in IDE.
   ws             :open working workspaces folder in File Explorer.
   env            :open Environment Variables panel.
   proms          :open Prompts folder (Template Replacer Extension) in File Explorer.
   appdata        :open mod AppData folder in File Explorer.
   mcp            :open MCP servers folder in File Explorer.
   skills         :open AI Skills folder in File Explorer.
   src-files [-c] :open Source-Files folder in File Explorer (or IDE with -c/--code).
   agy-mcp-conf   :open Antigravity MCP config file in Notepad.
   codex-mcp-conf :open OpenAI Codex MCP config file in Notepad.
   clau-mcp-conf  :open Claude Code MCP config file in Notepad.
   ssh-conf       :open SSH config file in Notepad.
   agy-skills     :open Antigravity skills folder in File Explorer.
   codex-skills   :open OpenAI Codex skills folder in File Explorer.
   clau-skills    :open Claude Code skills folder in File Explorer.
   <alias> [-c]   :open folder by registered alias in File Explorer (or IDE with -c/--code).
   add <alias> <path> :register a folder alias for quick opening.
   list, ls       :list all registered folder aliases.
   rm, remove <alias> :remove a registered folder alias.
## code:
                  :open mod files in vscode.
   test           :open testing folder in vscode.
   ws <value> [-p]:open working workspace in vscode and cd to working folder in CLI.
   ts-template    :open typescript template in vscode.
   js             :open testing javascript folder in vscode.
   ts             :open testing typescript folder in vscode.
   nestjs         :open testing nestjs folder in vscode.
   py             :open testing python folder in vscode.
   ext            :open extensions folder in vscode.
## edit:
   proms          :edit prompts in prompts folder in notepad (Template Replacer Extension).
   to             :edit to command in notepad (Template Replacer Extension).
   note           :edit useful commands in notepad.
## git:
   commit -m "msg":add all files and commit with a message and push with upstream.
   remote         :print git remote URL (git remote -v).
   dl-folder <url> [dest]
                  :download folder and all its contents recursively from GitHub repo (without .git).
                  // Example: mod git dl-folder "https://github.com/obra/superpowers/tree/main/skills/systematic-debugging" .
   dl-file <url> [dest]
                  :download single file from GitHub repo.
                  // Example: mod git dl-file "https://github.com/obra/superpowers/blob/main/skills/systematic-debugging/SKILL.md" .
   stash [list, ls]
                  :show list of git stashes in mod tool repository.
                  // Example: mod git stash list
                  // Example: mod git stash ls
   drop [stash_idx]
                  :drop a git stash interactively (like mod skill set) or by index/ref.
                  // Example: mod git drop
                  // Example: mod git drop 1
                  // Example: mod git stash drop
## run:
   unikey         :run unikey.
   gen-qr         :generate QR code image from input data.
                  // Example: mod run gen-qr
   keep-awake     :keep server awake by sending periodic requests to a specified URL with a specified interval.
                  // Example: mod run keep-awake "http://example.com/keep-alive" -i 5m
   keep-screen    :keep Windows screen awake until 'q' or 'Ctrl+C' is pressed.
                  // Example: mod run keep-screen
   srt-count-line :count lines in an srt file.
                  // Example: mod run srt-count-line "path/to/file.srt"
## file:
   create         :create files in standing folder in CLI.
   add-src <file> [--folder <name>]
                  :add file to centralized source-files template folder (supports recursive subfolder).
                  // Example: mod file add-src "D:/test.py" --folder "coding/farm"
   rename <folder_path> [prefix]
                  :rename files in specified folder with specified prefix.
                  // Example: mod file rename "D:/D-Documents/Làm về TikTok" "tiktok"
   delete <folder_path> <ext1,ext2,...>
                  :delete files in specified folder with specified extensions (comma-separated).
                  // Example: mod file delete "D:/D-Documents/Làm về TikTok" "txt,jpg,png"
   keep <folder_path> <ext>
                  :keep files in specified folder with specified extension, delete others.
                  // Example: mod file keep "D:/D-Documents/Làm về TikTok" "png"
## folder:
   cr-linear <path> [--content, -c <text>] [--file, -f] [--folder, -d]
                  :linearly create folder or file path with missing parent folders.
                  // Example: mod folder cr-linear "D:/projects/demo/app/main.py" --content "print('hello')"
                  // Example: mod folder cr-linear "D:/projects/demo/subfolder/"
   create <folder_path> [pattern] [starting_index] [num_folders]
                  :create one or multiple folders using a pattern.
                  // Example: mod folder create "D:/D-Documents/tool" "folder" 1 5
   dld-path [name]:set download path in Chrome.
   merge <from_folder> <to_folder> [-y] [--dry-run]
                  :check internal tree intersection & merge folder content from source to dest.
                  // Example: mod folder merge "D:/source_project" "D:/dest_project"
   tree [path] [--level, -l <N|deep>] [--max <N>]
                  :print folder tree structure with level depth control and auto-collapse.
                  // Example: mod folder tree
                  // Example: mod folder tree --level 1
                  // Example: mod folder tree "D:/projects" -l 2 --max 30
## print:
   os             :print OS info.
   pc-power [--notepad, -n]
                  :print detailed hardware specs (CPU, RAM, Disk, Wi-Fi, GPU).
                  // Example: mod print pc-power
                  // Example: mod print pc-power --notepad
   stts           :print mod-status description.
   ws             :print the folder vscode workspace.
   curl           :print CRUD of cURL command.
   dir            :print path of mod folder in system.
   note [--notepad, -n] [--find, -f <text>]
                  :print some useful commands with syntax highlighting or search blocks.
                  // Example: mod print note
                  // Example: mod print note --find "scp"
                  // Example: mod print note --find "git" --notepad

## gdrive:
   sync <source> <dest>
                  :sync a local folder to a gdrive folder.
                  // Example: mod gdrive sync "D:/D-Documents/tool" "mac_sync/tool"
   list [target_path] [-d] [--file]
                  :list folders on gdrive remote. Use -d for deep recursive listing, --file for files.
                  // Example: mod gdrive list "mac_sync" -d
   remote         :print selected remote info.
   del-fd <path>  :delete a folder on gdrive remote.
   url|link <path>:get share URL for a remote path.
   dl <url> [--dest <path>] [--folder <name>]
                  :download file from URL to local directory via gdrive dl tool.
                  // Example: mod gdrive dl "https://example.com/file.zip" --dest "."
   reset          :reset rclone configurations.
   guide          :display Google Drive authentication guide.

## gist:
    create [files...] [--desc <text>] [--public]
                   :create a new GitHub Gist from local files or interactively.
                   // Example: mod gist create "note.md" "config.json" --desc "My gist"
    list [--page N] [--limit N] [--all] [--public-only] [--secret-only]
                   :list GitHub Gists of the current account in a formatted table.
                   // Example: mod gist list --all
    get <gist_id> [--raw <filename>] [--save <output_dir>]
                   :view Gist metadata, print raw file content or save all files locally.
                   // Example: mod gist get 6a1b2c3d --raw "note.md"
    update <gist_id> [--add <name> <file>] [--delete <name>] [--desc <desc>]
                   :update files or description in an existing Gist.
                   // Example: mod gist update 6a1b2c3d --add "app.py" "src/app.py"
    delete <gist_id> [-y]
                   :permanently delete a Gist by ID with confirmation prompt.
                   // Example: mod gist delete 6a1b2c3d -y
    reset [gist_id] [-y]
                   :reset all Gists in account (if no gist_id) or reset specified Gist to a placeholder file.
                   // Example: mod gist reset -y
                   // Example: mod gist reset 6a1b2c3d
    audit          :audit storage usage, file types, large files (>8MB) and API rate limit.
                   // Example: mod gist audit
    rate           :check GitHub API rate limit status and reset time.
                   // Example: mod gist rate


## init:
   (no action)     :run init.cmd script.

## py:
   env            :setup python venv in current project.

## tunnel:
   [port]         :run quick cloudflare tunnel on specified port (default: 3000).
                  // Example: mod tunnel 8080

## proxy:
   test <ip>:<port>[:<login>:<password>] [--protocol socks5]
                  :test a proxy connection using Python, cURL and check IP via ipify.
                  // Example: mod proxy test 192.168.1.1:8080:user:pass --protocol http

## mcp:
   set [mcp_folder_name] [dest_folder_path]
                  :copy a folder from LOCAL_ABSOLUTE_FOLDER_PATH to dest_folder_path (only folders with direct README.md; enter 'q' to cancel).
                  // Example: mod mcp set iconify .
   open-config <agent_alias>
                  :open MCP configuration file of specified AI agent in Notepad.
                  // Supported agent aliases: anti (Antigravity), codex (OpenAI Codex), claude (Claude Code).
                  // Example: mod mcp open-config anti
                  // Example: mod mcp open-config codex
                  // Example: mod mcp open-config claude

## skill:
   set [skill_name] [dest_folder_path] [--ai, --llm, --agent <name>] [--project, --prj, -p [project_root]] [--keyword, --key, -k <keyword>] [--filter, -f <on-invocation|off-invocation>]
                  :copy a folder from SKILLS_FOLDER_PATH to dest_folder_path, AI Agent global skills directory (agy, codex, claude, all), or project standard .agents/skills folder.
                  // Example: mod skill set split-code .
                  // Example: mod skill set split-code --project "D:/my-project"
                  // Example: mod skill set split-code --prj
                  // Example: mod skill set --key ssr
                  // Example: mod skill set --keyword outside --prj
                  // Example: mod skill set watch-video --ai agy
                  // Example: mod skill set playwright --agent claude
                  // Example: mod skill set diagram-design --llm codex
                  // Example: mod skill set diagram-design --ai all
                  // Example: mod skill set --filter on-invocation
   project, prj, p [skill_name] [project_root] [--keyword, --key, -k <keyword>] [--filter, -f <on-invocation|off-invocation>]
                  :copy skill directly into project's standard .agents/skills directory (defaults to CWD).
                  // Example: mod skill project split-code "D:/my-project"
                  // Example: mod skill prj split-code
                  // Example: mod skill prj --key ssr
   remove, rm [skill_name] [--ai, --llm, --agent <name>] [--include-agent <name>] [--filter, -f <on-invocation|off-invocation>]
                  :remove skill from central repo (no flag), AI Agent only (--agent), or both (--include-agent).
                  // Example: mod skill remove split-code
                  // Example: mod skill rm --agent agy
                  // Example: mod skill rm --include-agent all
                  // Example: mod skill rm --filter on-invocation
   off-invocation, off-invo [skill_name] [--ai, --llm, --agent <name>] [--include-agent <name>] [--filter, -f <on-invocation|off-invocation>]
                  :disable AI auto-invocation by adding 'disable-model-invocation: true' to SKILL.md.
                  // Example: mod skill off-invocation access-web-fresh-data
                  // Example: mod skill off-invo --agent agy
                  // Example: mod skill off-invo --include-agent all
                  // Example: mod skill off-invo --filter on-invocation
   on-invocation, on-invo [skill_name] [--ai, --llm, --agent <name>] [--include-agent <name>] [--filter, -f <on-invocation|off-invocation>]
                  :enable AI auto-invocation by removing 'disable-model-invocation: true' from SKILL.md.
                  // Example: mod skill on-invocation access-web-fresh-data
                  // Example: mod skill on-invo --agent agy
                  // Example: mod skill on-invo --include-agent all
                  // Example: mod skill on-invo --filter off-invocation
   list, ls [--ai, --llm, --agent <name>] [--include-agent <name>]
                  :list skills in central repo (no flag), AI Agent only (--agent), or both (--include-agent).
                  // Example: mod skill list
                  // Example: mod skill ls --agent agy
                  // Example: mod skill list --include-agent all
   list-project, list-prj, ls-prj, ls-project [dest_folder_path]
                  :list all skills in specified project folder or current working directory.
                  // Example: mod skill list-project
                  // Example: mod skill list-project "D:/my-project"
                  // Example: mod skill list-prj .
   find, search <keyword>
                  :search all skills in central repo matching keyword in skill path.
                  // Example: mod skill find ssr
                  // Example: mod skill search outside
   open [-c]      :open AI Skills folder in File Explorer (or IDE with -c/--code). (Alias of 'mod open skills')
                  // Example: mod skill open
                  // Example: mod skill open -c

## toast:
   <title> [msg...] [--audio <path>]
                  :send a Windows desktop toast notification with title, message(s), and custom audio.
                  // Example: mod toast "Hoàn thành" "Product updated successfully." --audio "D:/sound.mp3"
   --syntax       :print 1-line command syntax of mod toast (easy to copy).

## compress:
    (no action)    :compress project into a zip file named 'mod-{dd}-{mm}-{yyyy}-{hh}-{mm}-{ss}.zip' using .compressignore.
                   // Example: mod compress
    folder <path> [--config-file <path>] [--ignore-file <path>]
                   :compress specified local folder using .compressignore or JSON rules (include-items, exclude-items).
                   // Example: mod compress folder "D:/my-project" --ignore-file ".compressignore"
    init-ignore <path> ["rules..."]
                   :create a starter .compressignore file at specified path or folder ('.' for current directory).
                   // Example: mod compress init-ignore . "*.log, temp/, .env"

## notify:
     send "<msg>" [--title <t>] [--channel <c>] [--priority <p>] [--tags <t>] [--url <u>] [--topic <topic>]
                    :send notification to specified channel (default channel: 'ntfy' on mobile app, default topic: 'any-mod-automation-N3RT8P2L').
                    // Example: mod notify send "Build successful!" --title "CI/CD" --channel ntfy --tags tada
                    // Example: mod notify send "Task completed" --channel telegram
                    // Example: mod notify send "Alert message" --channel toast
     test [--channel <c>] [--topic <topic>]
                    :send a test ping notification to verify connection and configuration.
                    // Example: mod notify test --channel ntfy
     channels       :list supported notification channels and their configuration statuses.
                    // Example: mod notify channels
     config         :display environment configuration guide for notification channels (.env).
                    // Example: mod notify config


# Example:
The command `mod --help` will print this content (help content).
The command `mod open ws` will open the working workspaces in system folder.
The command `mod compress` will compress current project to "mod-{timestamp}.zip" in root folder.
The command `mod compress folder --info` will explain how to use the command "mod compress folder".
The command `mod git commit -m "update"` will execute git add, commit and push.
The command `mod git dl-folder "<github_folder_url>" .` will download specified folder from GitHub without .git folder.
The command `mod git stash list` will show all stashes in mod repository.
The command `mod git drop` will prompt you to select a stash to drop.
The command `mod file delete "D:/path" "txt,jpg"` will delete files with specified extensions "txt" and "jpg".
The command `mod gdrive list "mac_sync" -d` will list all folders recursively.
The command `mod gdrive dl "https://example.com/file.zip"` will download file to current directory.
