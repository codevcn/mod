Mod CLI Production Architecture

Complete implementation topology mapping user CLI inputs through the Central Dispatcher, modular feature engines, notification hubs, external cloud integrations, and native Windows OS APIs.

ROUTING & DISPATCH

Central Dispatcher Architecture

  • Thin Windows entry point (mod.cmd) forwards input directly to src/main.py.
  • Manual sys.argv array parsing preserves complex arguments and avoid argparse overhead.
  • Interactive REPL shell with Windows msvcrt keystroke capture and Tab Autocomplete.
  • Three-tier documentation synchronization: main.py, help.txt, and app_features.yml.

EXECUTION SUBSYSTEMS

Modular Feature Engines

  • Autonomous scripts in src/features/ execute independently with forwarded parameters.
  • Cloud integrations: GitHub Gist REST API v3, Cloudflare Quick Tunnel, Google Drive (rclone).
  • OS automation: Keep-Screen via Win32 SetThreadExecutionState, Chrome downloader configs, venv init.
  • File workspace utilities: safe file deletion, tree generation, and dynamic project archive compression.

INTEGRATIONS & NOTIFICATIONS

Multi-Channel Dispatch & OS Native

  • Pluggable notification framework supporting ntfy.sh REST API, Telegram Bot API, and Windows Toast.
  • Audio sandbox bypass on Windows Action Center using native Win32 winmm.dll MCI playback.
  • Centralized paths management via src/configs/paths.py with dynamic workspace root detection.
  • Strict separation of secrets and environment credentials via project root .env file.
